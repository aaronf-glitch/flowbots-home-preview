Concept "Flux". A design mockup of the flowbots.ai homepage, not the live site.

- Live preview: see the GitHub Pages URL in this repo's Settings
- Single self-contained file: `index.html`. All logos, the world map and the
  Kevin O'Leary photo are embedded, so nothing can go missing.

## What is in it

hero, live AI console, integrations, the Kevin O'Leary proof section, what we

the $99 chatbot comparison, founders, guarantees, blog, FAQ, and the closing CTA.
